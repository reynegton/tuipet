tuipet.utils.anim

DVPet ambient-animation cadence, isolated as pure helpers so the timing is testable without Textual.

The whole engine rests on one invariant from the decompiled game: SpriteAnim sets _interval = targetFPS / 10 frames, so _interval is exactly 1/10 of a second and every _frame == _interval * N check fires N tenths of a second into a state. tuipet therefore drives animation on a single 10 Hz tick where one tick == one interval == 0.1 s, and each state below reproduces DVPet's beats one-for-one in real time, independent of frame rate.

Ground truth: _audit_src/View/SpriteAnim.java idleNormal :11246 idleWalk :11337 idleSleep :11525 idleUnwell :11447

 18STEP_PX = 2        # device-exact: 2px per beat over the 16px travel range
 19#                    (GML decompile 2026-07-14, obj_char_vpet Alarm_2; was 3)
 20TURN_CHANCE = 0.30 # device: irandom(100)>70 -- ~30% of beats flip direction
 21WALL_PAUSE = 4     # device limit_reach: 4 beats (2.0s) STOPPED at a wall on the

 38def sick_frame(frame: Any) -> Any:
 39    """idleUnwell: returns (sprite_index, dx_px).  Collapse pose (10) dominates the
 40    50-interval cycle; the weary pose (9) only flashes on the reset beat.  DVPet's
 41    shuffle is moveLeft1@30, moveRight1@35, moveRight1@40, moveLeft1@45 -- which is
 42    net-zero: the body sits 1px left over [30,35), back to centre [35,40), 1px right
 43    over [40,45), centre after.  (The pose offset is HELD across each range, not a
 44    one-frame blip.)"""
 45    f = frame % SICK_PERIOD
 46    if f == 49:
 47        idx = 9                            # brief weary flash before the reset
 48    else:
 49        idx = 10                           # collapsed the rest of the time
 50    if 30 <= f < 35:
 51        dx = -1
 52    elif 40 <= f < 45:
 53        dx = 1
 54    else:
 55        dx = 0
 56    return idx, dx

 59def mood_pose(pet: Any) -> Any:
 60    """DVPet stepFrame substitutes a `checkMoodFrame` expression pose for the plain
 61    walk toggle on a fraction of idle steps, so a resting pet *reads* its state:
 62    weary when spent, sour when unwell, bright when genuinely well-kept.
 63    Returns a sprite index, or None to keep the neutral walk toggle.
 64
 65    LIVE signals only (idle-pose audit 2026-07-18: the old mood/enthusiasm
 66    reads were FROZEN meters -- mood sat at its hatch value forever, so the
 67    bright pose fired constantly and the sour faces were unreachable):
 68    weary = the energy gauge; sour = the derived Unhappy word (sick /
 69    starving / filthy); bright = condition tier 3, the well-kept pet."""
 70    if pet.energy <= 0:
 71        return random.choice((10, 9, 2))      # weary / collapsed / droop
 72    if pet.current_mood() == "Triste":
 73        return random.choice((4, 6))          # sour faces
 74    if pet.condition() >= 3:
 75        return 5                              # bright: earned, not frozen-on
 76    return None                               # neutral -> ordinary walk pose

 79class Roamer:
 80    """Full-width pacing, after SpriteAnim.idleWalk: the pet steps STEP_PX every
 81    WALK_BEAT intervals, toggling its two walk poses.  DVPet's idleWalk *wraps*
 82    around the screen edges; on tuipet's tiny LCD we instead *turn around* at the
 83    walls (so the pet never vanishes) and occasionally about-face mid-room
 84    (TURN_CHANCE) so it wanders rather than marches.  A filth pile on the floor is
 85    a hard left wall it turns at."""
 86
 87    def __init__(self, x: Any, cols: Any, sprite_w: Any, face: int=1) -> None:
 88        self.x = float(x)
 89        self.cols = cols
 90        self.sw = sprite_w
 91        self.face = face          # +1 moving/looking right, -1 left
 92        self.pose = 0             # index into the two walk frames [0, 1]
 93        self.pause = 0            # wall-pause beats left (device limit_reach)
 94        self.stepped = False      # True on the interval a movement beat landed
 95        self._t = 0
 96        self._wall = 1            # departure direction once the pause ends
 97
 98    def step(self, left_bound: int=0, right_bound: Optional[Any]=None) -> None:
 99        """Advance one interval.  Movement happens on the WALK_BEAT cadence,
100        device-exact per the 2026-07-14 GML decompile (obj_char_vpet Alarm_2):
101        each beat picks a walk frame at RANDOM (50/50, not a strict toggle),
102        flips direction on ~30% of beats, and steps STEP_PX.  Hitting a wall
103        (screen edge, filth pile, status column) STOPS the pet for WALL_PAUSE
104        beats -- it stands on the turn pose pair -- then it departs the other
105        way.  (DVPet's idleWalk wrapped; the walls are tuipet's adaptation.)"""
106        self.stepped = False
107        self._t += 1
108        if self._t < WALK_BEAT:
109            return
110        self._t = 0
111        self.stepped = True
112        if self.pause:                               # stopped at the wall, turning
113            self.pause -= 1
114            self.pose ^= 1                           # the turn pair alternates
115            if self.pause == 0:                      # departure beat: face away and go
116                self.face = self._wall
117                self.x += self.face * STEP_PX
118            return
119        self.pose = random.getrandbits(1)            # device: 50/50 frame pick
120        if random.random() < TURN_CHANCE:            # device flips BEFORE moving
121            self.face = -self.face
122        self.x += self.face * STEP_PX
123        right_edge = self.cols - self.sw
124        if right_bound is not None:                  # a right-edge status column is a wall too
125            right_edge = min(right_edge, right_bound)
126        if self.x >= right_edge:                     # hit the right wall -> stop and turn
127            self.x = float(right_edge)
128            self.pause, self._wall = WALL_PAUSE, -1
129        elif self.x <= left_bound:                   # left wall / filth pile -> stop and turn
130            self.x = float(left_bound)
131            self.pause, self._wall = WALL_PAUSE, 1
132
133    @property
134    def xshift(self) -> Any:
135        """Offset from screen centre that render_screen expects (it centres first)."""
136        base = (self.cols - self.sw) // 2
137        return int(round(self.x)) - base
138
139    @property
140    def mirror(self) -> Any:
141        return self.face > 0          # sprites face left by default; mirror to face right
