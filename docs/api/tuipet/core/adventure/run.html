Adventure — the MARCH engine (rebuild phase 2, 2026-07-20).

⛔ OWN-GAME LAW (Joel 2026-07-13, carried forward): DVPet is NOT canon for adventures. One biome per run, start to the goal, no mid-run scenery swap.

Built: the MARCH (cross a zone in ~INTERACTIVE_STEPS travel actions, the journey on a ribbon, arrival ends the run); WILD ENCOUNTERS (a per-leg roll from the zone's own enemy table, lives, win/flee/loss/fail); and the real 26-ZONE GEOGRAPHY -- the zones come from data/zones.csv + enemies.csv (data.load_maps), each wearing ONE biome (its gate boss's terrain, no mid-zone span-hopping) with its own wild pool; the zone BOSS FIGHT -- reaching the end opens the gate boss (resolve_boss), and FELLING it is the real victory (a loss costs a life, 0 lives fails, a survivable loss lets the pet face it again); TRAVEL DRAIN -- each marched leg tires (energy), burns the calorie buffer (weight trims toward base) and tops the effort gauge, so a run comes home spent; TOWNS -- a mid-zone waypoint refills lives, rests energy to at least half the tank and suppresses encounters; and PROGRESSION -- pet.adv_progress tracks zones conquered (the frontier index); felling a zone's boss unlocks the next, and the ZonePickPanel lets the player embark on any unlocked zone; and FINDS -- a marched step may spot loot from the zone's own table (rand_items/rand_foods) to dig up or pass; the home STATUS CARD (statusbox.adventure_line: Quest N/26 on the home screen); and TRANSPORT items -- a town warp (Birdra) jumps to the town and rests, a danger warp (Garuda) dashes toward the boss and gets ambushed.

135    def _roll_encounter(self) -> Any:
136        """A wild enemy this leg, or None.  A town is safe ground (no roll);
137        immunity after a fight is spent first; then a per-leg roll, the pick
138        weighted by AppearanceChance."""
139        # grace is LEGS, not fights dodged: it spends on town ground too,
140        # else a pre-town fight banked a bonus free leg on the far side
141        # (audit 2026-07-25)
142        if self._immunity > 0:
143            self._immunity -= 1
144            return None
145        # the roll guards the leg being WALKED (the destination) -- the
146        # same leg find/hazard test after the step.  The old pre-step read
147        # made the walk OUT of town encounter-free and the walk IN
148        # ambushable on the doorstep, the town's safe ground off by one in
149        # one direction only (audit 2026-07-25)
150        if self._in_town(self.loc + 1):
151            return None                     # town ground: no wilds
152        if random.random() >= ENCOUNTER_CHANCE:
153            return None
154        pool = self._wild_pool()
155        if not pool:
156            return None
157        weights = [max(1, e.get("chance", 100)) for e in pool]
158        e = random.choices(pool, weights=weights, k=1)[0]
159        return _veteran(e) if self.replay else e

198                and not (self._transport_kind(k) == "danger"
199                         and self.loc >= self.total - 3)
200                # the lift buys legs too: hidden at the gate (2026-07-26)
201                and not (self._transport_kind(k) == "skip"
202                         and self.loc >= self.total - 1)
203                # the camp buys REST: hidden when the tank is already at

208    def use_transport(self, key: str) -> Any:
209        """Spend a road item.  Town warp -> jump to the town and rest
210        (lives + energy; the PANEL then offers the hub doors like any
211        walked-in arrival).  Danger warp -> dash toward the boss and get
212        ambushed on arrival.  Life Recovery -> hearts back to full where
213        you stand.  Returns 'town-warp', ('encounter', enemy),
214        'danger-warp', 'life-recovery', or None (not a run item / not
215        held / hearts already full)."""
216        kind = self._transport_kind(key)
217        inv = getattr(self.pet, "inventory", {}) or {}
218        if kind is None or inv.get(key, 0) <= 0 or self.done or self.failed:
219            return None
220        if kind == "life":
221            if self.lives >= MAX_LIVES:        # defensive: menu already hides it
222                return None
223            self.pet.take_item(key)
224            self.lives = MAX_LIVES
225            self.last = "A second wind — lives restored!"
226            return "life-recovery"
227        if kind == "town" and (self._in_town(self.loc)
228                               or not self.zone.get("town_legs")):
229            # defensive, like the life warp's full-hearts guard: the menu
230            # already hides it, and a ticket must never buy a rest you
231            # already have (adventure audit 2026-07-25)
232            return None
233        if kind == "danger" and self.loc >= self.total - 3:
234            # defensive: a dash that moves nothing is not for sale
235            return None
236        if kind == "skip" and self.loc >= self.total - 1:
237            return None                        # defensive: nothing to skip
238        if kind == "camp" and self.pet.energy >= self.pet.max_energy // 2:
239            return None                        # defensive: nothing to rest
240        if kind == "skip":
241            # the SAFE lift (expansion 2026-07-26): ten legs forward, no
242            # ambush, stopping shy of the gate -- the middle ticket between
243            # walking and the danger dash
244            self.pet.take_item(key)
245            self.loc = min(self.total - 1, self.loc + SKIP_LEGS)
246            self.last = "A Birdramon lift — the road slides by below."
247            return "skip-lift"
248        if kind == "camp":
249            # the Whamon CAMP: a rest without a town -- energy to half the
250            # tank where you stand.  Lives stay Life Recovery's job; the
251            # win streak survives (that is this ticket's premium)
252            self.pet.take_item(key)
253            half = self.pet.max_energy // 2
254            if self.pet.energy < half:
255                self.pet._set_energy(half)
256            self.last = "Camp pitched — rested where you stand."
257            return "camp-rest"
258        self.pet.take_item(key)
259        if kind == "town":
260            # the NEAREST town span, behind included: every zone's span
261            # ends mid-road, so a forward-only jump left the whole back
262            # half (and the gate) with a ticket that bought nothing.
263            # Doubling back re-walks real legs -- the ticket's price on
264            # top of its price (audit 2026-07-25).
265            legs = list(self.zone.get("town_legs") or ())
266            tgt = min(legs, key=lambda lg: min(abs(self.loc - lg[0]),
267                                               abs(self.loc - lg[1])))
268            self.loc = tgt[0]
269            self._rest_up()
270            self._resting = True
271            self.last = "Warped to a town — rested up."
272            return "town-warp"
273        # danger: dash to just shy of the boss gate, then an ambush
274        self.loc = max(self.loc, max(0, self.total - 3))
275        pool = self._wild_pool()
276        if pool:
277            weights = [max(1, e.get("chance", 100)) for e in pool]
278            enemy = random.choices(pool, weights=weights, k=1)[0]
279            if self.replay:
280                # the warp's ambusher is a VETERAN like every other wild on
281                # a conquered road -- the raw entry slipped the wrap while
282                # award_bits still paid the trained bounty (audit 2026-07-25)
283                enemy = _veteran(enemy)
284            self.last = f"Warped ahead — ambushed by {enemy['name']}!"
285            return ("encounter", enemy)
286        self.last = "Warped ahead."
287        return "danger-warp"

289    def _roll_find(self) -> Any:
290        """A loot key spotted on the road this step, or None (no finds in a
291        town -- the pet is resting, not scavenging)."""
292        pool = self.zone.get("find_keys") or ()
293        if not pool or self._in_town(self.loc):
294            return None
295        chance = FIND_CHANCE * (HOLIDAY_FIND_MULT if self.holiday else 1)
296        if random.random() >= chance:
297            return None
298        # a FESTIVAL road present IS A CAPSULE now (item expansion
299        # 2026-07-26, Joel: "rewire christmas presents to basically be
300        # holiday versions of these"): the wrapped box lands in the bag and
301        # is OPENED for its roll -- opened on the festival day, the roll
302        # reaches a tier higher (petcare._capsule); two of the ten boxes
303        # are the authored AngrySurprise pranks.  Home gifts stay home.
304        if self.holiday and random.random() < FESTIVAL_PRESENT_CHANCE:
305            return (random.choice(_FESTIVAL_CAPSULES), True)
306        # TIERED FIND RARITY (D1, 2026-07-24): the pool used to be a flat
307        # random.choice, so a zone's legendary signature turned up exactly as
308        # often as its cheapest snack.  Weighted by the same tier ladder the
309        # shelves read -- common 8 : uncommon 4 : rare 2 : legendary 1.
310        import tuipet.core.shop as shop
311        weights = [shop.tier_weight(k) for k in pool]
312        return (random.choices(list(pool), weights=weights, k=1)[0], False)

339    def _rest_up(self) -> None:
340        """A town rest, wherever it comes from (waypoint or warp): lives back,
341        energy rested to at least HALF the tank (topped by TOWN_REST_ENERGY
342        when already above it) -- and the WIN STREAK breaks.  One rest, one
343        price, both doors (the waypoint rests on arrival -- there is no
344        push-on choice there; truthed 2026-07-25).  (D1 ruling
345        2026-07-23: the old flat +6 was one battle's worth -- "rested up" that
346        a single fight erased; half a tank makes the words true, and a pet
347        KNOCKED past empty warping in comes back standing.)"""
348        self.lives = MAX_LIVES
349        self.pet._set_energy(max(self.pet.energy + TOWN_REST_ENERGY,
350                                 self.pet.max_energy // 2))
351        # THE TOWN IS THE ROAD'S SICKBED (audit 2026-07-25): injury is the
352        # one ailment a run itself inflicts (fight rolls), and with the
353        # clock parked it could never heal -- measured, an ideal pet was 4x
354        # likelier to be turned back hurt at the gate than to lose the
355        # boss.  A rest patches it, and cures a sickness carried in (the
356        # sick trudge's pilgrimage; the home cures are free too, so the
357        # town gives away nothing the F menu doesn't).  Mirrors the cure
358        # verbs' own writes (petcare pill/bandage) exactly.
359        self.pet.sick = False
360        self.pet.injured = False
361        self.pet.inj_length = 0.0
362        self.streak = 0

386    def award_bits(self, enemy: Any) -> Any:
387        """Pay out a beaten enemy's bounty (enemies.csv BitsWon range): a wild
388        pays a little, a gate boss pays a lot.  Adds to the pet's purse and the
389        run tally, returns the amount."""
390        lo, hi = enemy.get("bits") or (1, 5)
391        lo, hi = min(lo, hi), max(lo, hi)
392        amt = random.randint(lo, hi) if hi > 0 else 0
393        if amt and self.holiday:
394            amt *= HOLIDAY_BITS_MULT        # festival purse
395        if amt:
396            amt = round(amt * self.streak_mult())   # the chained-win bonus
397        if amt and self.replay:
398            amt = amt * REPLAY_BITS_NUM // REPLAY_BITS_DEN   # veteran bounty
399            if enemy.get("boss"):
400                # THE REPLAY BOUNTY IS RATIONED (anti-printer, audit
401                # 2026-07-25): a conquered boss pays its veteran purse once
402                # per real day per zone -- the town_bought idiom.  Unbounded,
403                # the festival x streak x veteran stack paid ~18,000b per
404                # repeatable 8-minute run against a 51,677b whole-catalog;
405                # every other earner is rationed (cup: the hour; town rows:
406                # the daily cap; raid: attempts).  Wilds still pay, and a
407                # FIRST conquest is untouched.
408                import tuipet.core.shop as shop
409                zi = zone_index(self.zone)
410                if zi is not None:
411                    day = shop._today_ordinal()
412                    led = dict(getattr(self.pet, "road_bounty", None) or {})
413                    if led.get("day") != day:
414                        led = {"day": day}
415                    if led.get(str(zi)):
416                        amt, self.bounty_spent = 0, True
417                    else:
418                        led[str(zi)] = 1
419                    self.pet.road_bounty = led
420        if amt:
421            self.pet.bits += amt
422            self.bits_earned += amt
423        return amt

425    def award_drop(self, enemy: Any) -> Any:
426        """THE BATTLE DROP (item expansion 2026-07-26, Joel: "i even want
427        battle drops in adventure") -- and it was AUTHORED all along:
428        every enemies.csv row carries a LootTableID into dropRate.csv.
429        Wilds shed attribute chips at 2-7%, elites shed the X-Program at
430        100%, and each map's unique story boss drops its RELIC.
431
432        Rationing rides the bounty's own rules: a REPLAY boss whose daily
433        veteran purse is spent drops nothing either (the road_bounty
434        ledger, anti-printer) -- wilds stay live, a first conquest is
435        untouched.  Returns the granted CATALOG key, or None."""
436        if enemy.get("boss") and self.replay and self.bounty_spent:
437            return None
438        table = data.load_loot_tables().get(enemy.get("loot_table", -1))
439        if not table:
440            return None
441        import tuipet.core.shop as shop
442        from tuipet.core.pet import Pet
443        roll, cum = random.random() * 100, 0
444        for icon, rate in table:
445            cum += rate
446            if roll < cum:
447                # a Relic drop speaks the crest shelf's own key; all
448                # else resolves through the one icon->key door

482    def _march_drain(self) -> None:
483        """One marched leg's toll: it tires (energy), burns the calorie buffer
484        (weight trims toward the species base when it bottoms out), and tops the
485        effort gauge -- travel is light training.  Applied on a leg cadence."""
486        from tuipet.core.pet import CALORIE_LIMIT
487        self._drain_acc += 1
488        if self._drain_acc < WALK_DRAIN_EVERY:
489            return
490        self._drain_acc = 0
491        p = self.pet
492        p._set_energy(max(0, p.energy - TRAVEL_ENERGY_DEC))
493        p.calories -= TRAVEL_CALORIE_DEC
494        if p.calories <= -CALORIE_LIMIT:            # buffer bottomed: shed a weight unit
495            p.calories = CALORIE_LIMIT
496            p._set_weight(max(p._base_weight(), p.weight - 1))
497        if p.strength < TRAVEL_EFFORT_CAP:          # light training tops the effort gauge
498            p.strength += 1

500    # -- the march ------------------------------------------------------------
501    def travel(self) -> Any:
502        """Advance one step down the road -- unless a wild blocks it.  Returns
503        ('encounter', enemy) when one fires (no progress that leg), 'arrived'
504        on the step that reaches the goal (the run is `done`), 'step'
505        otherwise, None if the run is already over."""
506        if self.done or self.failed:
507            return None
508        if self.pet.check_stop_travel():
509            # canTravel (restored 2026-07-21): a pet pushed PAST EMPTY plants
510            # its feet -- today's deliberately-soft calibration (petcare:
511            # negative energy only), NEVER the old chance-based refusal
512            self.last = f"{self.pet.name} refuses to walk!"
513            return ("refused", None)
514        enemy = self._roll_encounter()
515        if enemy is not None:
516            self.last = f"A wild {enemy['name']} blocks the road!"
517            return ("encounter", enemy)
518        self.loc += 1
519        self._march_drain()              # the leg's toll: energy / calories / effort
520        if self._in_town(self.loc):
521            if not self._resting:        # just stepped into a town: rest up
522                self._resting = True
523                self._rest_up()
524                self.last = f"Reached a town in {self.name} — rested up."
525                return "town"
526        else:
527            self._resting = False
528        if self.loc >= self.total:
529            self.loc = self.total
530            if self.boss is not None:
531                # the boss GATES the end -- crossing is not the win, felling it is
532                self.last = f"{self.boss_name} guards the gate!"
533                return ("boss", self.boss)
534            self.done = True             # a bossless zone: the crossing is the win
535            self.last = f"{self.name} crossed!"
536            return "arrived"
537        # DANGER ROLLS BEFORE TREASURE (audit 2026-07-25): the find used to
538        # shadow the hazard, so doubling FIND_CHANCE on a festival quietly
539        # cut ambushes ~14% -- a festival must never make the road SAFER
540        haz = self._roll_hazard()
541        if haz is not None:
542            self.last = "Something rustles ahead!"
543            return ("hazard", haz)
544        find = self._roll_find()
545        if find is not None:
546            key, present = find
547            self.last = ("A present sits on the road!" if present
548                         else "Something glints on the road.")
549            return ("find", key, present)
550        self.last = f"{self.name} — {self.pct}%"
551        return "step"

553    def resolve_boss(self, won: Any, fled: bool=False) -> Any:
554        """Settle the gate boss.  won -> the zone is CONQUERED (done); fled ->
555        turned back at the gate, no victory (not a failure); lost -> a life, and
556        at 0 lives the run FAILS; 'retry' keeps the pet at the gate to try
557        again.  Returns 'won' | 'fled' | 'lost'... 'retry' | 'failed'."""
558        if won:
559            self.done = True
560            self.last = f"{self.boss_name} felled — {self.name} conquered!"
561            return "won"
562        if fled:
563            self.last = f"Retreated from {self.boss_name}."
564            return "fled"
565        self.lives -= 1
566        if self.lives <= 0:
567            self.lives = 0
568            self.failed = True
569            self.last = f"{self.boss_name} was too strong."
570            return "failed"
571        unit = "life" if self.lives == 1 else "lives"
572        self.last = f"Knocked back by {self.boss_name} — {self.lives} {unit} left."
573        return "retry"
