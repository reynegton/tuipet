tuipet.ui.screens.shopscreen

The shop + bag screen (the DSprite item system, cloned from the v0.4.x rebuild -- BASIC VPET 2026-07-16; polish pass 2026-07-17).

LAYOUT (the classic v0.5.0 grammar, restored on Joel's call 2026-07-17 "where are the tabs you had like before?"): a visible TAB BAR under the header ([Food] Items Eggs Honors, active bracketed), then the selected entry's ICON + four info rows (menu.icon_info -- the one layout every icon view shares), then the list, then the footer. The DSprite catalog groups into the classic four tabs; the bag keeps its own bar (Food / Items / Eggs over what you own). ENTER buys / uses (a crest egg fires the classic armor evolution), R sells back half, TAB flips shop<->bag.

Art law: consumables have NO DSprite icon rips (vitems carries only id/name/price/category), so their icon cell stays quiet -- never substitute lookalike art. The crest eggs show the small Relic item glyphs DVPet ITSELF draws (drawEvolutionInventory's Items-sheet icon, via the Pet._CREST_IDS identity the item flow uses) -- Joel 2026-07-18: "8x8 item icons, like how the rest of the shop is"; the armorEggs.png ghost-egg scene was tried and REMOVED same day (fan- authored, unused even by DVPet). The Honors crest is the drawn text plate (allowed: a plate, not art -- the CLOSED-sign precedent).

Info rows are a LIVE dossier -- price with held count / shortfall, effect, and a crest egg names the form that would answer it RIGHT NOW (the same evolution.check the item runs). Buy/sell verdicts flash in the footer (they were beep-only before -- self.msg was never rendered); the sealed Relic waves tease there on the egg-carousel cadence.

159    def _grouped(self, rows: Any, tab_name: Any, cats: Any) -> Any:
160        """P4: sort the Items tab by CATEGORY and slip a dim sub-header in
161        front of each run.  Header rows are NOT selectable -- `_snap` walks
162        the cursor past them, and every consumer guards on `.get("header")`.
163
164        Only the Items tab groups: it is the one tab holding more than one
165        category, and a header over a single-category list is noise."""
166        if tab_name != _GROUPED_TAB or not rows:
167            return rows
168        order = [c for c in shop.CATEGORY_ORDER if c in set(cats or ())]
169        def rank(e: Any) -> Any:
170            c = e.get("category", "")
171            return (order.index(c) if c in order else len(order), e["name"])
172        out, last = [], None
173        for e in sorted(rows, key=rank):
174            cat = e.get("category", "")
175            if cat != last:
176                last = cat
177                out.append({"header": cat, "name": cat, "category": cat})
178            out.append(e)
179        return out

185    def _snap(self, rows: Any, idx: int, step: int=1) -> Any:
186        """Move OFF a header row in `step` direction; never loops forever
187        (a list of nothing but headers can't happen, but guard anyway)."""
188        n = len(rows)
189        if not n:
190            return 0
191        idx %= n
192        for _ in range(n):
193            if not self._is_header(rows[idx]):
194                return idx
195            idx = (idx + step) % n
196        return idx

198    def _normalize_cursor(self, rows: Any) -> None:
199        """Never leave the cursor parked on a header (opening a tab, a
200        list that shrank under it, restored session position)."""
201        if not rows:
202            self.cursor = 0
203            return
204        self.cursor = min(self.cursor, len(rows) - 1)
205        if self._is_header(rows[self.cursor]):
206            self.cursor = self._snap(rows, self.cursor, 1)

208    def _rows(self) -> Any:
209        tabs = self._tabs()
210        name = tabs[self.tab % len(tabs)]
211        cats = dict(GROUPS)[name]
212        if self.mode == "shop":
213            if cats is None:            # the HONORS board (prestige sink)
214                owned = persistence.get_titles_owned()
215                worn = persistence.get_title_worn()
216                return [dict(t, title_id=t["id"], owned=t["id"] in owned,
217                             worn=t["id"] == worn)
218                        for t in data.load_titles()]
219            if self.town is not None:      # the town counter: authored stock
220                if name == "Eggs":         # the egg band, shop-row shape
221                    return shop.town_egg_rows(self.town)
222                return self._grouped(
223                    [e for e in shop.town_stock(self.town, pet=self.pet)
224                     if e["category"] in cats], name, cats)
225            return self._grouped(
226                [e for e in shop.home_stock(pet=self.pet)
227                 if e["category"] in cats], name, cats)
228        out = []
229        for k, n in self.pet.inventory.items():
230            e = shop.entry(k)
231            if e and e["category"] in cats:  # type: ignore
232                e = dict(e, count=n)
233                if self.town is not None:  # local demand: the town's OWN offer
234                    e["sell_price"] = shop.town_sell_price(k, self.town)
235                out.append(e)
236        out.sort(key=lambda e: e["name"])      # by the name you SEE, not the key
237        return self._grouped(out, name, cats)

258    def _use(self, e: Any) -> Any:
259        p = self.pet
260        old = p.num
261        key = e["key"]
262        # the chip clears its payload on success; the inherit fx needs it
263        mem = dict(p.peek_memory()) if key == "memory" else None
264        out = p.use_item(key)
265        if p.num != old:                        # a crest egg fired the armor jump
266            return ("done", ("evolve", old))
267        if out is None:
268            self._flash("Você não tem isso.")
269            self.sfx = "error"  # type: ignore
270            return None
271        if out == "":
272            self._flash(f"{e['name']} não faz nada aqui.")
273            return None
274        from tuipet.core.petbase import Refused
275        refused = isinstance(out, Refused)      # kept the item: no show plays
276        if not refused and shop.item_is_eaten(key):
277            # the bag CLOSES and the item is EATEN on the LCD through its
278            # own DVPet strip -- the eat fx the feed menu rides (TUIPET
279            # catalog 2026-07-18; the _after_shop route was waiting for
280            # this).  Gated on the SHEET (item-show audit 2026-07-23), not
281            # on the Food CATEGORY as it once was: the food-sheet
282            # CONSUMABLES -- both drinks, both pills, the vitamin, the
283            # anti-evo chip -- are eaten too, and used to flash bare text
284            # over ripped art.  (That rival category set, shop.FOOD_KEYS,
285            # was cut 2026-07-25; item_is_eaten is the one answer.)
286            return ("done", ("eat", shop.ICON_KEYS.get(key, "f:0"), out))
287        if not refused and (_sc := shop.item_script(key)):
288            # the item's SHOW: its CANON itemfx script on the main LCD
289            # (item-show audit 2026-07-23: this used to read a 7-entry
290            # hand-map of toys, so the textbook/dumbbell/music player/
291            # grow capsule flashed text while their scripts sat written
292            # and their ripped art sat unused)
293            return ("done", ("item_use", shop.ICON_KEYS[key], _sc, out))
294        if not refused and key == "memory" and mem:
295            # the heir redeems the ancestor: the bag closes and the canon
296            # inherit fx plays on the LCD (_after_shop's waiting route)
297            return ("done", ("inherit", mem))
298        self._flash(out)
299        self.sfx = "error" if refused else "confirm"   # type: ignore
300        return None

302    def _arm_deal_guard(self, key: str) -> None:
303        """A deal purchase just landed: if that was the LAST cut-price copy,
304        arm the one-press guard (the bag's `_retarget` grammar) so the next
305        ENTER on the same row can't quietly pay full price."""
306        if any(r.get("key") == key and r.get("deal") for r in self._rows()):
307            return                        # copies left: the deal still stands
308        self._deal_guard = key  # type: ignore

315    def _check_retarget(self, e: Any) -> None:
316        """After a bag use/sell: if that emptied the stack, the list shifts
317        under the cursor -- arm the one-press guard so a mashed R/ENTER
318        can't silently hit the neighbor (QOL 2026-07-23)."""
319        key = e.get("key")
320        if key is not None and all(r.get("key") != key for r in self._rows()
321                                   if not self._is_header(r)):
322            self._retarget = True

324    def key(self, k: Any) -> Any:
325        rows = self._rows()
326        self._normalize_cursor(rows)
327        n = len(rows)
328        tabs = self._tabs()
329        if k in ("left", "h", "right", "l", "up", "k", "down", "j",
330                 "pageup", "pagedown", "tab"):
331            self._retarget = False           # the player re-aimed on purpose
332        if k == "tab" and not self.bag_only:
333            self._tab_pos[(self.mode, self.tab)] = self.cursor
334            self._mode_pos[self.mode] = (self.tab, self.cursor)
335            self.mode = "bag" if self.mode == "shop" else "shop"
336            self.tab, self.cursor = self._mode_pos.get(self.mode, (0, 0))
337            self._normalize_cursor(self._rows())
338            self._flash("Sua mochila." if self.mode == "bag" else "Bem-vindo de volta!")
339            return None
340        if k in ("left", "h"):
341            self._tab_pos[(self.mode, self.tab)] = self.cursor
342            self.tab = (self.tab - 1) % len(tabs)
343            self.cursor = self._tab_pos.get((self.mode, self.tab), 0)
344            self._normalize_cursor(self._rows())
345        elif k in ("right", "l"):
346            self._tab_pos[(self.mode, self.tab)] = self.cursor
347            self.tab = (self.tab + 1) % len(tabs)
348            self.cursor = self._tab_pos.get((self.mode, self.tab), 0)
349            self._normalize_cursor(self._rows())
350        elif k in ("up", "k") and n:
351            self.cursor = self._snap(rows, (self.cursor - 1) % n, -1)
352        elif k in ("down", "j") and n:
353            self.cursor = self._snap(rows, (self.cursor + 1) % n, 1)
354        elif k in ("pageup", "pagedown"):     # the shelf/bag leap (help audit 2026-07-21)
355            step = menu.page_step(self.cursor, n, 5, k)
356            # a leap can land ON a header: walk the way the leap was
357            # going, then back off if that ran out of list
358            self.cursor = self._snap(rows, step,
359                                     1 if k == "pagedown" else -1)
360        elif k in ("enter", "space") and n:
361            e = rows[self.cursor % n]
362            if self._is_header(e):        # a sub-header is a label, not a buy
363                return None
364            if self.mode == "shop":
365                if (self._deal_guard is not None
366                        and self._deal_guard == e.get("key")
367                        and not e.get("deal")):
368                    # the bargain went with the last press, but the row
369                    # still sells at FULL price -- say which before a
370                    # mash spends four times the bits it meant to
371                    self._deal_guard = None
372                    self._flash("a oferta sumiu — ENTER de novo por %db"
373                                % e["price"])
374                    self.sfx = "cancel"
375                    return None
376                if e.get("title_id") is not None:
377                    msg, self.sfx = self._buy_title(e)
378                    self._flash(msg)
379                elif e.get("egg_idx") is not None:
380                    msg, self.sfx = shop.town_egg_buy(self.pet, e["egg_idx"])
381                    self._flash(msg)
382                elif (self.town is not None or e.get("deal")
383                        or e.get("left") is not None):
384                    # a RATIONED row is rationed wherever it stands: town
385                    # counters always were, the home deal joined 2026-07-24,
386                    # and the home capsule ration joined 2026-07-26 -- one
387                    # buy path for all, so the ledger is written exactly once
388                    msg, self.sfx = shop.town_buy(self.pet, e)
389                    self._flash(msg)
390                    if e.get("deal") and self.sfx == "confirm":
391                        self._arm_deal_guard(e["key"])
392                else:
393                    msg, self.sfx = shop.buy(self.pet, e)
394                    self._flash(msg)
395            else:
396                if self._retarget:
397                    self._retarget = False
398                    self._flash(f"agora em {e['name']} — aperte de novo")
399                    self.sfx = "cancel"  # type: ignore
400                    return None
401                r = self._use(e)
402                if r is not None:
403                    self._remember_pos()   # a toy/inherit exit closes the bag
404                    return r
405                self._check_retarget(e)
406        elif k == "r" and self.mode == "bag" and n:
407            e = rows[self.cursor % n]
408            if self._is_header(e):
409                return None
410            if self._retarget:
411                self._retarget = False
412                self._flash(f"agora em {e['name']} — aperte de novo")
413                self.sfx = "cancel"  # type: ignore
414                return None
415            msg, self.sfx = shop.sell(self.pet, e)
416            self._flash(msg)
417            self._check_retarget(e)
418        elif k in ("escape", "s", "b"):
419            # the opening keys close (bar tidy 2026-07-18); s/b since the
420            # mnemonic remap 2026-07-28 (was o shop / i bag)
421            # carry a still-live verdict home (round 31: keying on self.sfx
422            # was dead -- the app consumes sfx every frame, so buy-then-
423            # leave never showed its verdict)
424            self._remember_pos()
425            return ("done", self.msg if self.msg_t > 0 else None)
426        # a buy/sell/use can RESHAPE the list under the cursor -- a sold-out
427        # town row drops away, a spent stack empties -- and that can slide a
428        # sub-header under it.  Re-snap on the way out so the cursor is never
429        # parked on a label between one keypress and the next render (P4).
430        self._normalize_cursor(self._rows())
431        return None
