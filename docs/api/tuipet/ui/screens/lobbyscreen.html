tuipet.ui.screens.lobbyscreen

Multiplayer lobby panel — name login, presence, chat, jogress + battle sessions.

Chat-focused layout: a scrolling chat log on the left, a roster sidebar on the right. Phases:

name type a handle, Enter to join (only when no cached tamer name) lobby chat default; Up/Down pick a player; Enter on empty input opens that player's action menu ([B]attle / [J]ogress); invites pop a [Y]/[N] jogress both relay their pet's attribute, each resolves its fusion locally (jogress.resolve), shows the result, Enter evolves the pet battle seeded symmetric PvP (proto 2, canon BattleProtocol's peer-symmetric exchange with the desync solved): both relay battle cards carrying a nonce COMMITMENT, reveal the nonce with the first pick, and derive a shared PRNG seed -- then each round both exchange only their FINAL attribute pick and each side resolves the identical card-vs-card engine locally. Neither peer trusts the other's arithmetic, so the monthly ladder's both-reports-must-agree check is real. A peer whose card has no "proto" gets the pre-2 host-authoritative relay verbatim (the inviter resolves and mirrors absolute results). PvP wins record onto the pet (evolution credit) just like PvE.

Decoupled from the app: on_connect(name, card) -> LobbyClient lets the app own the WebSocket worker's lifecycle. Colours come from the live theme.

373    def _enter_session(self, pid: Any, pname: Any, kind: Any, host: Any) -> None:
374        if self.invite_prompt is not None:
375            # a CROSSED invite (both players invited each other): entering the
376            # session must consume the other prompt, or it survives the whole
377            # bout and re-offers a dead invite back in the lobby (session
378            # audit 2026-07-07)
379            inv = self.invite_prompt
380            self.invite_prompt = None
381            self.client.respond(inv.get("from_id"), inv.get("kind"), False, busy=True)
382        self.partner = (pid, pname)  # type: ignore
383        if kind == "jogress":
384            card = self._card()
385            opts = jogress.options(self.pet)
386            self.client.relay(pid, {"kind": "jogress", "attr": card["attr"],  # type: ignore
387                                    "num": card["num"], "name": card["name"],
388                                    # canon JogressProtocol.sendPlayerInfo ships the
389                                    # jogressMatch string (reachable fusion NAMES +
390                                    # pairable attributes) and the growth stage --
391                                    # they drive the mutual both-or-neither match
392                                    # (session audit 2026-07-07)
393                                    "stage": self.pet.stage,
394                                    "fusions": [o["name"] for o in opts],
395                                    # exact-door companions I need (canon
396                                    # one-sided jogress, audit 2026-07-17)
397                                    "wants": [o["partner_num"] for o in opts
398                                              if not o["partners"]],
399                                    "attrs": jogress.pairable_attrs(self.pet),
400                                    # canon JogressProtocol ships the REAL sick
401                                    # state: fusing with a sick partner is a 90%
402                                    # catch (jogress audit 2026-07-06)
403                                    "sick": bool(getattr(self.pet, "sick", False)),
404                                    # two-phase commit capability (consent audit
405                                    # 2026-07-07): both players confirm at the
406                                    # result screen before either pet fuses
407                                    "confirm2": True})
408            self.phase, self.jphase = "jogress", "waiting"  # type: ignore
409            self.status = t("lob_msg_fusing", "Fusing with {name}…").format(name=pname)
410        elif kind == "battle":
411            self.is_host = host
412            self.phase, self.bphase = "battle", "card"
413            card = battle.battle_card(self.pet)
414            # the engine input must be the card AS THE PEER WILL SEE IT, so
415            # clamp my own card exactly like _battle_begin clamps theirs
416            self.bt_my_card = _clamp_card(card)
417            # commit-reveal seed handshake: the nonce is COMMITTED before either
418            # side has seen the other's (cards cross in flight), and revealed
419            # with the first pick -- so neither client can grind the shared
