tuipet.ui.screens.dnascreen

DNA screen -- the device's DNA sub-screens.

Home menu (DVPet DNA_Validation): Charge / Generate / Stats / Divergence. (The Requirements viewer left with the DNA slim -- gate-forgiveness died with it; this docstring lagged until the DNA review 2026-07-18.)

  • Charge (DNA_Inventory + DNA_Detail): spend banked DNA into the pet, bending evolution toward forms whose Field-DNA gates you meet. The bill is ENERGY: 1/unit on your own Field, doubled off-Field (the old spirit/mood/illness costs left with their systems). On commit the pet absorbs it (the DNA_Feeding "dnaWash" fx plays on the display).
  • Generate (DNA_GenerateValidate + DNA_Generate): wager bits, mash SPACE ~10s; a faster mash earns a rarer Field (getDNARate bands), too slow/fast -> the dud None field. The won Field blinks in (the UnlockDNA reveal).
  • Stats (DNA_Stats): each Field's charged share -- the evolution gate %.
  • Divergence (tuipet, "ultimate v-pet" arc 2026-07-07): the wild-road map -- where each Field's charge can steer the NEXT evolution off the chart (evolution.divergence_roads), the stage threshold, and the armed state. The door must be visible to be a choice.

 42def _field_word(f: Any, w: Any) -> Any:
 43    """pretty_field fitted to `w` at a WORD boundary: a column too narrow for
 44    the full name shows whole words only -- "Pesadelo", never the mid-word
 45    run-off "Nightmare Sold" the old char-slices printed (menu audit
 46    2026-07-21).  Every field's first word is unique, so a one-word tag
 47    still names it."""
 48    s = data.pretty_field(f)
 49    if len(s) <= w:
 50        return s
 51    cut = s[:w]
 52    return cut.rsplit(" ", 1)[0] if " " in cut else cut

 83    def _armed(self) -> Any:
 84        """The strict-max charged Field at/over the stage threshold WITH a
 85        road -- the next evolution will diverge (mirrors divergence_target's
 86        gate without picking the destination)."""
 87        f = self.pet.highest_dna()
 88        need = evolution.DIVERGE_NEED.get(self.pet.stage)

 90                and self.pet.dna_applied.get(f, 0) >= need and f in self._roads):
 91            return f
 92        return ""

101    def _rate(self) -> Any:
102        """rate = ceil(hits / time * 10), time in seconds. At the 10s mark this is
103        just your total hit count, so the Field = how many presses you land."""
104        if self.mash_f <= 0:
105            return 0
106        return int(math.ceil(self.hits / (self.mash_f / 10.0) * 10.0))

108    def anim(self) -> None:
109        self.frame_i += 1
110        if self.phase == "mash":
111            self.mash_f += 1
112            if self.mash_f >= MASH_TICKS:
113                rate = self._rate()
114                owned0 = dict(self.pet.dna_owned)
115                bits0 = self.pet.bits
116                field = self.pet.dna_minigame_award(self.bet, rate)
117                # the result page reports what actually LANDED: near the 99
118                # cap the overflow refunds as bits, and "Got 99" while 9
119                # banked was a lie (DNA review 2026-07-18)
120                banked = self.pet.dna_owned.get(field, 0) - owned0.get(field, 0)
121                refund = self.pet.bits - bits0
122                self.won = (field, self.bet, rate, banked, refund)  # type: ignore
123                self.phase = "result"
124                self.blink = 0
125                self.sfx = "mischief"    # type: ignore
126        elif self.phase == "result":
127            self.blink += 1              # drive the won-Field blink reveal

134    def _key_home(self, k: Any) -> Any:
135        if k in ("up", "k"):
136            self.home_i = (self.home_i - 1) % len(_HOME)
137        elif k in ("down", "j"):
138            self.home_i = (self.home_i + 1) % len(_HOME)
139        elif k in ("enter", "space", "right", "l"):
140            self.phase = _HOME[self.home_i][0]
141            if self.phase == "generate":
142                self.phase = "bet"
143                self.bet = max(1, min(MAX_DNA_INVENTORY, self.amount))
144            self.sfx = "select"  # type: ignore
145        elif k in ("escape", "x"):
146            return ("done", None)
147        return None

149    def _key_charge(self, k: Any) -> Any:
150        p = self.pet
151        f = self.charge_fields[self.cursor % len(self.charge_fields)]
152        if k in ("up", "k"):
153            self.cursor = (self.cursor - 1) % len(self.charge_fields)
154        elif k in ("down", "j"):
155            self.cursor = (self.cursor + 1) % len(self.charge_fields)
156        elif k in ("left", "h"):
157            self.amount = max(1, self.amount - 1)
158        elif k in ("right", "l"):
159            self.amount = min(MAX_DNA_INVENTORY, self.amount + 1)
160        elif k in ("enter", "space"):
161            amt = min(self.amount, p.dna_owned.get(f, 0))
162            if amt <= 0:
163                self.last = t("dna_msg_no_banked", "No banked {fld} yet.").format(fld=data.pretty_field(f))
164                self.sfx = "error"  # type: ignore
165            elif p.apply_dna(f, amt):
166                self.sfx = "compatible"  # type: ignore
167                return ("done", ("charged", f, amt))   # close -> DNA_Feeding absorb fx
168        elif k == "escape":
169            self.phase = "home"
170        return None

382    def strip(self) -> Any:

394                              ("ENTER", t("dna_hint_enter_charge", "charge")))

396            return menu.hints(("←→", t("dna_hint_wager", "wager")), ("ENTER", t("dna_hint_enter_mash", "mash!")),
397                              ("ESC", t("dna_hint_back_only", "ESC back")[-4:]))
